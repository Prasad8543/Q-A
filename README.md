# Q-A
Question and Answers Website

This website contains a Login Page/Signup Page for user login or signup.
Once the user logs in or sign up into the app then he will redirected to Questions home page where he can see list of questions and no of answers for each question.
If we click on no of answers it will redirect to answers page for that question.


Steps:
Clone this project.
pip3 install -r requirement/base.txt
